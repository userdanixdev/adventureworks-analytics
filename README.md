# AdventureWorks Analytics

Projeto de estudo utilizando o banco de dados fictício **AdventureWorks**, disponibilizado pela Microsoft.

A análise tem foco em **vendas e-commerce**, explorando vendas, clientes, produtos, períodos e indicadores financeiros.

## Tecnologias

SQL Server · dbt · Power BI · Python · Git

## Documentação

Acesse a documentação do projeto para consultar as perguntas de negócio, insights e boas práticas aplicadas.

## Fonte dos dados

[AdventureWorks — Microsoft](https://github.com/Microsoft/sql-server-samples/tree/master/samples/databases/adventure-works)

Os dados são fictícios e destinados a estudos e demonstrações.
